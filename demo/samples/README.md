# 연습용 샘플 파일

'연습 폴더 초기화'를 누르면 `manifest.json`에 적힌 대로 이 파일들을 **지저분한 이름**(예: `다운로드 (7).pdf`)으로
`demo/inbox`에 복사합니다. 이름·계좌·번호는 모두 지어낸 예시입니다.

- 다시 만들기: `python scripts/make_samples.py` (LibreOffice·Noto Sans CJK 글꼴 필요)
- `hwp_sample.hwp`: [neolord0/hwplib](https://github.com/neolord0/hwplib)의 샘플 (Apache-2.0, `LICENSE-hwplib.txt`)
